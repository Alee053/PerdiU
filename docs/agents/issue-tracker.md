# Issue tracker: GitHub

Issues live in `Alee053/PerdiU`; the sprint is tracked in [PerdiU Backlog](https://github.com/users/Alee053/projects/5).

Read tickets with `gh issue view <number> --repo Alee053/PerdiU --comments`. Read the project with `gh project item-list 5 --owner Alee053`. Use existing issue labels and project statuses. Remote writes, pushes and PR creation require authorization from the current task.

Follow [CONTRIBUTING.md](../../CONTRIBUTING.md) for naming, PR templates, closing references, project linkage and review transitions; it is the shared source of these conventions.

PRs as a request surface: no.
