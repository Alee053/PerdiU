# API de PerdiU

Este workspace queda reservado para la API que se sumará en la siguiente etapa. La primera entrega es una demo frontend; aquí se definirán autenticación, publicaciones, moderación y persistencia cuando se acuerde el backend.

Las estructuras compartidas entre `apps/web` y la API se mantienen en `packages/contracts`. El paquete `@perdiu/api` ya está registrado en el workspace, sin servidor ni decisiones de framework fijadas para esta demo.
